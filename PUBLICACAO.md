# Publicação do bingo

A fonte editorial está em liturgia/projects/catequese/dinamicas.
O diretório bloco_10_13_bingo_liberdade contém uma cópia publicada das fontes,
dos PDFs e do registro de revisão desse bingo. A edição continua no workspace
liturgia; os arquivos publicados acompanham os dados distribuídos pelo PWA.
As cartelas já impressas estão congeladas por data/cartelas_impressas.lock.json.
Este repositório recebe o PWA e os bundles gerados para deploy por push em main.
Use npm run build:published em pwa; não regenere com as pastas históricas.
Os materiais publicados em pwa/public são derivados; edite as fontes no liturgia.
A preparação é feita pelo script prepare-git-publish.py do workspace liturgia.

O diretório bingo_geral_catequese contém a edição geral Conhecer e viver a fé,
com as fontes canônicas, o panorama próprio, 75 chamadas e 24 cartelas.
A edição segue no workspace liturgia; esta cópia acompanha a publicação.
